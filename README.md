# index-page-slider

Self-contained Vue 3 + Vite + TypeScript + Tailwind CSS 4 demo of the
`IndexPageSlider` block. Uses local mock data only, no backend requests.

## Stack

- Vue 3
- Vite
- TypeScript (strict)
- Tailwind CSS 4
- Icons: inline SVG (Font Awesome Free chevron paths), no webfont/CDN

## Getting started

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
```
